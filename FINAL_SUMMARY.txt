COMPLETE WORKFLOW
=================

User clicks toolbar button
  ↓
React handler executes (useCallback)
  ↓
Calls imageToolbarApi.method()
  ↓
HTTP POST to /api/v1/image-toolbar/{endpoint}
  ↓
FastAPI validates request (Pydantic)
  ↓
Authentication check (JWT)
  ↓
ImageProcessingService method executes
  ↓
Downloads image from URL
  ↓
Processes using PIL
  ↓
Uploads result to storage
  ↓
Returns URL in response
  ↓
Frontend fetches result image
  ↓
Saves to IndexedDB
  ↓
Updates Zustand store
  ↓
Component re-renders
