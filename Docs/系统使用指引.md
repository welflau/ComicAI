## 1. 快速开始

### 最简流程（5 步出片）

```
① 注册账号并登录
        ↓
② 新建项目，粘贴剧本
        ↓
③ 点击顶栏「解析剧本」→ 等待完成
        ↓
④ 依次点击「生成分镜」→「生成图像」→「合成配音」→「智能剪辑」
        ↓
⑤ 切换到「预览」视图，查看并导出视频
```

## 2. 注册与登录

### 注册

1. 访问系统首页，点击「**立即注册**」
2. 填写用户名、邮箱、密码（≥ 8 位）
3. 点击「创建账号」，注册成功后自动登录并跳转到项目看板

### 登录

1. 在登录页输入注册时的邮箱和密码
2. 点击「登录」进入项目看板
3. 支持「显示/隐藏密码」切换（点击输入框右侧眼睛图标）

> **提示**：登录状态会在浏览器本地持久化，关闭标签页后重新打开无需重新登录。

## 3. 项目看板

登录后首先进入**项目看板（Dashboard）**，这里管理你的所有漫剧项目。

### 新建项目

1. 点击右上角「**＋ 新建项目**」按钮
2. 在弹窗中填写：
   - **项目名称**（必填）：如「晴天漫画第一季」
   - **项目描述**（选填）：简要描述内容
3. 点击「创建项目」，完成后自动进入编辑器

| 操作 | 方法 |
|------|------|
| 打开项目 | 点击卡片任意区域 |

| 切换视图 | 右上角网格图标（⊞）/ 列表图标（≡）切换 |

| 状态 | 含义 |
|------|------|

| 制作中 | 正在进行 AI 生成流程 |

| 已归档 | 归档保存，不再编辑 |

| 颜色 | 类别 | 说明 |
|------|------|------|
| 🔵 蓝色 | 输入节点 | 数据输入起点，如剧本输入 |

| 🔴 红色 | 输出节点 | 最终输出，如预览、导出 |
| 🟣 紫色 | 控制节点 | 流程控制（条件分支等） |

### 默认工作流

系统创建项目时会自动生成一套完整的默认工作流：

```
[剧本输入] → [AI剧本解析] → [分镜生成] → [图像生成] → [智能剪辑] → [预览]
                                      ↘ [配音合成] ↗
```

### 节点操作

| 操作 | 方法 |
|------|------|
| 移动节点 | 拖拽节点到目标位置 |
| 选中节点 | 单击节点（右侧面板显示其属性） |
| 连接节点 | 拖拽节点右侧的输出连接点到另一节点左侧的输入点 |
| 添加节点 | 从**左侧节点库**拖拽节点到画布空白处 |

| ❌ 红色「失败」 | 任务执行失败，可查看运行日志 |

## 6. 一键运行 AI 管线

顶部工具栏提供 5 个快捷按钮，**按从左到右的顺序依次执行**：

### 第一步：解析剧本

1. 确保已在项目中创建剧本（或通过 API 导入）
2. 点击「**解析剧本**」按钮
3. AI（GPT-4o 或 Claude）自动解析剧本，提取：
   - 场景列表（时间、地点、氛围）
   - 人物信息（姓名、性格、外貌描述）
   - 每段对白和动作描述
4. 等待右侧运行日志显示「完成」

### 第二步：生成分镜

1. 解析完成后，点击「**生成分镜**」
2. AI 根据剧本结构自动规划每个镜头：
   - 镜头类型（远景/中景/近景/特写等）
   - 镜头时长（秒）
   - 摄像机运动（推拉摇移等）
   - 英文图像提示词（供后续图像生成使用）
3. 完成后切换到「分镜板」视图可查看所有镜头卡片

### 第三步：生成图像

1. 点击「**生成图像**」
2. 系统批量调用图像 AI（DALL-E 3 / Stability AI）为每个镜头绘制分镜图
3. 生成过程中分镜板会逐渐显示预览图（实时刷新）
4. 图像风格由项目配置的 `visual_style` 参数控制（默认漫画风）

### 第四步：合成配音

1. 点击「**合成配音**」
2. 系统提取所有有对白的镜头，调用 Azure TTS 生成配音
3. 支持情感控制（SSML），匹配角色对白的语气
4. 完成后分镜卡片右下角出现 🎤 蓝色图标

### 第五步：智能剪辑

1. 点击「**智能剪辑**」
2. AI 剪辑引擎自动：
   - 根据镜头时长排列视频/图像片段
   - 添加 Ken Burns 镜头运动效果
   - 合并配音轨、BGM 轨、字幕轨
   - 生成完整时间轴 JSON
3. 完成后切换到「时间轴」视图查看完整剪辑结果

> **提示**：每步操作后可在右侧「运行日志」面板查看实时进度，任务失败时会显示具体错误信息。

## 10. 左侧面板 — 节点库与素材库

左侧面板在**工作流视图**下显示，包含两个标签页。

### 节点库

提供所有可用的工作流节点，按类别分组：

**输入节点（蓝色）**
- `剧本输入` — 导入或粘贴剧本文本

**处理节点（绿色）**
- `AI 剧本解析` — 智能解析剧本结构
- `分镜生成` — 自动生成分镜脚本
- `角色设计` — 设计一致性角色形象
- `场景设计` — 生成场景背景图
- `图像生成` — AI 绘图生成分镜图
- `视频生成` — 图片转视频动态效果
- `配音合成` — AI 语音合成配音
- `背景音乐` — AI 生成背景音乐
- `智能剪辑` — 自动剪辑合成视频

**输出节点（红色）**
- `预览` — 实时预览生成效果
- `导出` — 导出最终视频文件

**搜索节点**：在节点库顶部搜索框输入关键词快速定位

**添加节点到画布**：将节点从列表**拖拽**到中央画布空白处即可添加

### 素材库

管理项目中已上传或已生成的媒体素材：

| 标签 | 内容 |
|------|------|
| 全部 | 所有素材 |
| 图片 | 分镜图、角色图、背景图 |
| 视频 | 生成的视频片段 |
| 音频 | 配音文件、BGM |
| 剧本 | 上传的剧本文件 |

## 11. 右侧面板 — 属性 / AI 助手 / 运行日志

右侧面板始终显示，包含三个标签页。

### 属性（Properties）

选中工作流中的节点后，此面板显示该节点的详细信息：

- **节点名称**与**运行状态徽章**
- **进度条**（任务运行中时显示实时进度）
- **配置参数**：可直接编辑节点的配置项（如图像风格、语音 ID 等），失去焦点后自动保存

> 未选中任何节点时显示「选择节点查看属性」提示。

### AI 助手（Chat）

内置的 AI 创作助手，可以帮助你：

- **优化剧本**：「帮我把这段对白改得更有张力」
- **设计角色**：「给我设计一个冷酷侦探的外形描述」
- **生成提示词**：「把这段场景描述转换成 DALL-E 的英文提示词」
- **创作建议**：「这个场景的镜头切换节奏怎么优化？」
- **答疑解惑**：「分镜生成失败了，可能是什么原因？」

**使用方式**：
1. 在底部输入框输入问题
2. 按 `Enter` 或点击发送按钮（✈️）
3. AI 流式返回回答

### 运行日志（Log）

实时显示所有 AI 生成任务的执行记录：

- 任务类型（如「图像生成」）
- 当前状态（待机 / 运行中 / 已完成 / 失败）
- 运行中任务显示实时进度条
- 失败任务显示错误信息摘要
- 提交时间（精确到秒）

## 12. 实时协作

ComicFlow AI 支持多人同时在线编辑同一个项目。

### 开启协作

- 将项目链接（`/project/{projectId}`）分享给团队成员
- 所有人打开同一链接即自动加入协作会话

### 协作功能

| 功能 | 说明 |
|------|------|
| 在线状态 | 顶栏右侧显示当前在线人数的头像 |
| 连接状态 | 绿色 Wifi 图标 = 协作服务已连接 |
| 光标同步 | 其他用户在画布上的操作位置实时同步 |
| 操作同步 | 节点移动、连接变更实时同步到所有客户端 |
| 冲突解决 | 基于 OT（操作变换）算法自动处理并发编辑冲突 |

> **注意**：协作功能需要服务端 WebSocket 服务正常运行（`/ws/collab/{projectId}`）。

## 13. 常见问题

### Q：点击「生成图像」后一直没有进展？

**A**：检查以下几点：
1. 右侧「运行日志」中查看任务状态，是否显示「失败」及错误信息
2. 确认 `.env` 中的 `OPENAI_API_KEY` 或 `STABILITY_API_KEY` 已正确填写
3. 确认已先完成「生成分镜」步骤（需要分镜数据才能生成图像）
4. 检查 Celery Worker 是否正在运行：`docker compose ps worker`

---

### Q：分镜板显示「暂无分镜」？

**A**：需要先完成以下步骤：
1. 创建剧本（通过 API 或未来的剧本编辑器）
2. 点击「解析剧本」等待完成
3. 点击「生成分镜」等待完成
4. 刷新页面后切换到分镜板视图

---

### Q：配音合成的语音听起来不对？

**A**：可以在右侧属性面板中修改 `tts` 节点的 `voice_id` 参数。内置语音选项：

| voice_id | 说明 |
|----------|------|
| `zh_female_gentle` | 温柔女声（默认） |
| `zh_male_serious` | 严肃男声 |
| `zh_female_lively` | 活泼女声 |
| `zh_male_young` | 年轻男声 |
| `zh_narrator` | 旁白播音腔 |

---

### Q：时间轴中视频片段没有实际视频，只有图片？

**A**：图像生成后默认以静帧展示。如需动态视频片段，需要先运行 `video_gen`（视频生成）节点，该步骤调用 Replicate SVD 将图像转换为短视频，耗时较长（每个镜头约 1～3 分钟），建议仅对关键镜头启用。

---

### Q：多人协作时右上角显示「离线」？

**A**：
1. 确认后端 WebSocket 服务正在运行
2. 检查 Nginx 配置中 `/ws/` 路径是否已正确代理
3. 刷新页面重新建立 WebSocket 连接
4. 检查防火墙是否阻止了 WebSocket 连接

---

### Q：如何更换 AI 图像风格？

**A**：在工作流视图中单击「图像生成」节点，在右侧属性面板修改 `style` 参数：

| 参数值 | 风格说明 |
|--------|---------|
| `manga` | 日式漫画风（默认） |
| `comic` | 美式漫画风 |
| `anime` | 动漫风 |
| `realistic` | 写实风格 |
| `watercolor` | 水彩插画风 |

---

### Q：如何导出最终视频？

**A**：
1. 确保已完成所有生成步骤（至少完成智能剪辑）
2. 在工作流画布中找到「导出」节点
3. 在右侧属性面板配置导出格式（分辨率、码率等）
4. 运行「导出」节点，完成后从运行日志中获取下载链接

> 当前版本导出功能通过后端 API 触发，生成文件存储在 MinIO 对象存储中，可通过预签名 URL 下载。
