## 启动方式

### 生产环境（Docker）

```bash
# 1. 复制并配置环境变量
cp .env.example .env
# 编辑 .env，填入 API 密钥和数据库密码

# 2. 启动全部服务
docker compose up -d

# 3. 查看服务状态
docker compose ps
```

启动后访问：

| 服务 | 地址 |
|------|------|
| 前端应用 | http://localhost |
| API 文档 (Swagger) | http://localhost/api/v1/docs |
| Flower 任务监控 | http://localhost:5555 |
| MinIO 控制台 | http://localhost:9001 |

### 本地开发

**后端：**
```bash
cd backend
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

**Celery Worker：**
```bash
cd backend
celery -A app.tasks.worker.celery_app worker --loglevel=info -Q generation,default
```

**前端：**
```bash
cd frontend
npm install
npm run dev    # 访问 http://localhost:5173
```

## API 接口速查

```
# 认证
POST /api/v1/auth/register          注册
POST /api/v1/auth/login             登录
GET  /api/v1/auth/me                当前用户

# 项目
GET    /api/v1/projects             项目列表
POST   /api/v1/projects             创建项目
GET    /api/v1/projects/{id}        项目详情
PATCH  /api/v1/projects/{id}        更新项目
DELETE /api/v1/projects/{id}        删除项目

# 剧本
GET  /api/v1/projects/{id}/scripts          剧本列表
POST /api/v1/projects/{id}/scripts          创建剧本

# 分镜
GET   /api/v1/projects/{id}/storyboards     分镜列表
PATCH /api/v1/projects/{id}/storyboards/{sid}  更新分镜

# 任务（AI 生成）
GET  /api/v1/projects/{id}/tasks            任务列表
POST /api/v1/projects/{id}/tasks            提交任务
GET  /api/v1/projects/{id}/tasks/{tid}      任务状态

# AI 助手
POST /api/v1/ai/assistant           对话
POST /api/v1/ai/optimize-prompt     优化提示词

# 素材上传
POST /api/v1/assets/upload/{id}     上传文件

# 实时协作
WS   /ws/collab/{project_id}        WebSocket 协作频道
```

## 环境变量说明

| `SECRET_KEY` | JWT 签名密钥（≥32位随机字符串） | — |
