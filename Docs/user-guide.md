## 欢迎使用 ComicFlow

### 快速开始

> ⏱ 阅读时间 2min

ComicFlow AI 是一个 **AI 漫剧智能创作平台**，把剧本创作、图片生成、视频制作串联成一条完整的创作流水线。

**注册 / 登录**

1. 访问应用，点击「注册」创建账号
2. 填写用户名、邮箱、密码
3. 登录后进入「我的项目」

**新建项目**

1. 点击右上角 **+ 新建项目**
2. 填写项目名称（必填）和描述（选填）
3. 进入项目后自动打开画布

---

### 基本能力

> ⏱ 阅读时间 2min

巧用 AI「魔法」，挖掘属于你自己的独特用法吧

**文本能力**

- 文本生文本：生成灵感、生成脚本
- 文本生图片：比如输入指令「给我一张猫咪的图片」，即可得到对应内容的图片
- 文本生视频：比如输入指令「生成一个女人在喝咖啡的视频」，即可得到对应内容的视频

**图片能力**

- 图片生文本：**总结**图片内容
- 单图修改：**修改已有的图片**，完成图片元素的「增、删、改」
- 图片生图片（多张）：上传多张图分别作为**风格参考图、场景参考图**等，生成指定文字内容的图片
- 图片生视频（单张）：将上传的图片作为**首帧图**生成指定文字内容的视频
- 图片生视频（两张）：将上传的图片分别作为**首、尾帧**生成指定文字内容的视频

**视频能力**

- 视频生文本：分析视频剪辑技巧
- 视频生视频：支持对已有视频进行风格转换和延伸

## 我的画布

### 认识画布

> ⏱ 阅读时间 2min

欢迎来到 ComicFlow 画布

画布是一个非常有趣的概念。

小时候我们喜欢拿着根笔在一张白纸上乱涂乱抹——从 UGC 走到 AIGC 的今天，我们手中的**铅笔**变成了 **AI 魔法**，一张**白纸**变成了 ComicFlow 的**无限画布**。

但灵感不变、创意不变。变的是，更快了，也更方便了。Agent 与你一起协同办公。

**为什么是无限画布？**

| 优势 | 说明 |
|---|---|
| 素材永久沉淀 | 图片视频一次上传、多次复用，永久沉淀到资产库，再也不用反复上传 |
| 文图影音自由切换 | 文字 → 图片 → 视频 任意双向切换，创意即刻「眼见为实」 |
| 最新模型第一时间可用 | 接入 Seedance、Kling 等最先进模型，持续更新 |
| 一键模板 + 工作流 | 沉淀实战经验的模板和 SOP，拿来即用 |
| Agent 自动化 | Agent 模式可在后台自动完成工作，解放双手 |

**界面布局**

| 区域 | 说明 |
|---|---|
| 顶栏 | 项目名称、视图切换（画布 / 分镜 / 时间轴）、分享、历史记录 |
| 左侧工具栏 | 添加节点、节点列表、分镜视图、历史、角色库 |
| 画布区 | 节点拖拽、连线、缩放的主操作区 |
| 底部 | 日志面板 |

**画布基本操作**

| 操作 | 方式 |
|---|---|
| 移动画布 | 按住空格拖拽，或双指滑动 |
| 缩放 | 滚轮 / 触控板双指缩放 |
| 选中节点 | 单击节点 |
| 多选节点 | 按住 Shift 点击，或鼠标框选 |
| 删除节点 | 选中后按 Delete / Backspace |
| 连接节点 | 拖拽节点右侧 `+` 手柄到目标节点左侧手柄 |

### 认识节点

> ⏱ 阅读时间 2min

节点是画布上的**最小创作单元**。每个节点代表一种媒体内容或 AI 操作，节点之间通过连线传递数据，构成完整的创作流程。

**节点类型**

| 节点 | 功能 |
|---|---|
| 图片节点 | 存储和生成图片，可上传本地文件或 AI 生图 |
| 视频节点 | 存储和生成视频，支持多种 AI 生视频模式 |
| 脚本节点 | AI 辅助撰写漫剧脚本，流式输出 |
| 分镜节点 | 管理分镜表格，关联图片与场景描述 |

**节点解剖**

每个节点从上到下分为三部分：

```
[ 标题栏 ]        ← 节点名称 + 右上角操作按钮（上传、替换）
[ 内容区 ]        ← 图片 / 视频 / 文本的展示区域
[ 提示词面板 ]    ← 选中节点后展开，用于下达 AI 指令
```

---

### 创建节点

点击画布底部 **+** 按钮，或拖拽已有节点的 `+` 手柄，弹出节点选择菜单：

- 📄 脚本
- 🖼 图片
- 🎬 视频
- 🎵 音频（即将上线）

选择类型后节点自动添加到画布当前位置。

**连接节点**

拖拽节点右侧的 `+` 手柄 → 释放到目标节点上，即可建立连接。

连接后，上游节点的产出（图片 URL、视频 URL）会作为下游节点的参考输入，无需手动复制粘贴。

---

### 使用节点

#### 输入框

每个节点下方有一个**输入框**，用来给 AI 下达文字指令。比如，你可以在输入框中写入「根据这张图给我一些灵感」。

节点框内也内置了三个快捷选项，点击后 AI 将直接执行该指令：

1. 粘贴或输入文本内容
2. 写一段创意广告脚本
3. 写一段生成城市背景的提示词

#### 指令优化器

输入框右侧的**星星按钮**是指令优化器。

点击后将把你输入的文字指令改写为更专业的生成指令，以确保生成更精准、更符合需求的「魔法咒语」。

> 示例：输入「一位女学生拿着笔在写作业」→ 点击指令优化器 → 得到包含光线、构图、风格描述的完整出图指令

#### 执行次数

节点底部的「**1×**」表示当前设置的执行次数。

- 选中「**2×**」将执行此指令两次，同时生成两个结果
- 通过这种「抽卡」方式可以得到更满意的素材

### 使用工具栏

#### 节点工具栏

每个节点内容区右上角都有一个**内置多功能工具栏**：

**图片节点工具栏**

| 按钮 | 功能 |
|---|---|
| 全屏 | 放大查看图片细节 |
| 下载 | 保存图片到本地 |
| 抠图 | AI 自动去除背景 |
| 高清 | AI 超分辨率放大 |
| 扩图 | 向外延伸扩展画面 |
| 图片编辑器 | 进入精细编辑模式 |

**视频节点工具栏**

| 按钮 | 功能 |
|---|---|
| 全屏 | 全屏播放视频 |
| 下载 | 保存视频到本地 |

#### 多选工具栏

按住 Shift 点击或框选多个节点后，顶部浮现多选工具栏：

- **复制** — 将选中节点序列化到剪贴板
- **复制粘贴** — 偏移 40px 创建副本
- **删除** — 批量删除节点及关联连线

## 创意生视频案例

### 图生视频

> 以一张图片为起点，生成对应的视频片段

**步骤**

1. 添加一个**图片节点**，上传或 AI 生成你的参考图（角色图、场景图均可）
2. 添加一个**视频节点**，将图片节点连线到视频节点
3. 选中视频节点，切换到「**图生视频**」标签
4. 此时提示词面板下方会显示引用图片的缩略图，确认参考内容无误
5. 选择模型（Seedance 1.5 / Kling 3.0）和参数
6. 输入运镜描述，点击发送

**运镜提示词参考**

| 效果 | 示例提示词 |
|---|---|
| 推镜 | `相机缓缓向主体推进，聚焦在面部表情` |
| 拉镜 | `相机拉远，从人物特写到城市全景` |
| 环绕 | `相机环绕主体旋转一圈，光线从左侧入射` |
| 跟随 | `跟随人物行走，保持人物在画面左三分之一` |
| 固定 | `固定机位，主体由远及近走向镜头` |

### 首尾帧视频

> 指定视频的开头和结尾画面，AI 自动补全中间的运动过程

**步骤**

1. 添加**视频节点**，点击画布内快捷操作「**首尾帧生成视频**」
2. 系统自动在左侧创建**首帧**和**尾帧**两个图片节点并完成连线
3. 分别为首帧和尾帧图片节点上传对应图片
4. 选中视频节点，切换到「**首尾帧**」标签
5. 输入过渡描述（如：`光线从清晨变为黄昏，人物保持姿势不变`）
6. 选择参数，发送生成

**适用场景**

- 人物从 A 地点移动到 B 地点
- 场景从白天变化到夜晚
- 产品展示的旋转 / 角度切换
- 情绪变化的面部过渡

## 提示词技巧

### 通用提示词优化器

在任意节点的输入框中，点击**星星按钮**即可一键优化提示词。

优化器会自动补充：主体描述、背景环境、光线质感、构图方式、画面风格等专业要素。

> 建议先用自然语言描述你的想法，再点击优化器改写，效率最高。

---

### 即梦 Seedance 提示词技巧

**参数配置**

| 参数 | 推荐值 | 说明 |
|---|---|---|
| 比例 | Auto | 即梦自动识别最佳比例 |
| 清晰度 | 720P | 平衡质量与生成速度 |
| 时长 | 5s | 短镜头，适合分镜级内容 |
| 音频 | 关闭 | 后期配音更灵活 |

**提示词结构**

```
[主体描述] + [动作/状态] + [环境/背景] + [运镜方式] + [光线/氛围]
```

示例：
> `一个年轻女性站在雨中的街道上，手持雨伞缓缓转身，背景是模糊的霓虹灯光，相机从侧面缓缓推进，暖色调，电影感`

---

### 可灵 Kling 提示词技巧

**参数配置**

| 参数 | 推荐值 | 说明 |
|---|---|---|
| 比例 | 16:9 | 横版视频，适合大部分场景 |
| 时长 | 5s | 单镜头控制在 5s 内 |
| 音频 | 关闭 | 建议后期单独处理声音 |

**适用场景**

- 需要精准控制画面比例（竖版短视频用 9:16）
- 角色动作幅度较大的场景
- 需要明确首帧参考的图生视频

**提示词注意事项**

- 避免在提示词中出现两个及以上运动主体，容易混淆
- 运镜描述放在句尾，避免干扰主体生成
- 极端光线（全黑 / 全白）场景建议降低清晰度要求
