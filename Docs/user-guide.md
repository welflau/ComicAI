## 快速开始

ComicFlow AI 是一个 **AI 漫剧智能创作平台**，通过节点式画布将剧本创作、图片生成、视频制作串联成完整的创作流水线。

### 注册 / 登录

1. 访问应用地址，点击「注册」创建账号
2. 填写用户名、邮箱、密码完成注册
3. 使用邮箱 + 密码登录

### 新建项目

1. 进入「我的项目」页面，点击右上角 **+ 新建项目**
2. 填写项目名称（必填）和描述（选填）
3. 点击确认后进入项目画布

## 认识画布

画布是 ComicFlow AI 的核心创作空间——一块无限延伸的白板，你可以在上面自由放置节点、连线、组织创作流程。

### 界面布局

| 区域 | 说明 |
|---|---|
| 顶栏 | 项目名称、视图切换、分享、历史记录 |
| 画布区 | 节点拖拽、连线、缩放 |
| 底部 | 添加节点菜单、日志面板 |

### 视图模式

- **画布视图** — 节点工作流，主创作区
- **分镜视图** — 按顺序展示所有图片/分镜格
- **时间轴视图** — 视频剪辑时间轴

### 基本操作

| 操作 | 方式 |
|---|---|
| 移动画布 | 按住空格拖拽，或双指滑动 |
| 缩放 | 滚轮 / 触控板双指缩放 |
| 选中节点 | 单击节点 |
| 多选节点 | 按住 Shift 点击，或框选 |
| 连接节点 | 拖拽节点右侧 `+` 手柄到目标节点 |
| 删除节点 | 选中后按 Delete / Backspace |

### 节点连接

每个节点左侧有**输入手柄**（`+`），右侧有**输出手柄**（`+`）。  
拖拽输出手柄到另一个节点的输入手柄，即可建立数据流向连接。

连接后，上游节点的产出（图片、视频等）可作为下游节点的参考输入。

### 多选工具栏

选中多个节点后，顶部浮现工具栏，支持：
- **复制** — 序列化到剪贴板
- **复制粘贴** — 偏移 40px 创建副本
- **删除** — 批量删除选中节点及关联连线

## 节点系统

点击画布底部 **+** 按钮，或拖拽节点手柄选择「添加节点」，可插入以下类型：

| 节点类型 | 功能 |
|---|---|
| 图片节点 | 上传图片 / AI 生图 |
| 视频节点 | 上传视频 / AI 生视频 |
| 脚本节点 | AI 生成剧本脚本 |
| 分镜节点 | 管理分镜表格 |

---

## 图片节点

图片节点用于管理单张图片，支持本地上传和 AI 生成两种方式。

### 上传图片

选中节点后，点击节点上方浮现的「上传」按钮，选择本地图片文件（支持 PNG、JPG、WebP）。

### AI 生图

选中节点后展开底部提示词面板：

1. 在文本框中输入描述（支持中英文）
2. 点击右下角发送按钮，等待生成
3. 生成完成后图片自动显示在节点中

### 图片用作参考

将图片节点通过连线连接到视频节点，图片即可作为视频生成的参考帧。

---

## 视频节点

视频节点是 ComicFlow AI 的核心功能，支持多种视频生成模式和模型选择。

### 上传视频

选中节点后点击「上传」按钮，支持 MP4、WebM 格式。上传完成后视频自动循环播放。

### AI 生视频

选中节点后展开底部提示词面板，选择生成模式：

| 模式 | 说明 |
|---|---|
| 文生视频 | 纯文字描述生成视频 |
| 全能参考 | 结合多种参考生成 |
| 图生视频 | 以上游图片为参考帧生成 |
| 首尾帧 | 以首帧+尾帧控制视频内容 |
| 图片参考 | 以图片风格/内容为参考 |

### 快捷操作

无连接节点时，画布内显示快捷入口：

- **首尾帧生成视频** — 自动在左侧创建首帧+尾帧图片节点并连线
- **首帧生成视频** — 自动创建首帧图片节点并连线

### 选择模型

点击底部工具栏左侧的模型选择器，展开模型菜单：

| 模型 | 平台 | 特点 |
|---|---|---|
| Seedance 1.5 | 即梦 | 高质量长视频，自适应画面比例 |
| Kling 3.0 | 可灵 | 专业级视频生成，支持多种比例 |

点击对应模型即可切换，当前选中模型高亮显示。

### 视频参数

点击底部工具栏参数按钮（显示当前参数值，如 `Auto · 720P · 5s 🔇`），展开参数面板：

**比例**

| 模型 | 可选值 |
|---|---|
| 可灵 | 16:9 / 9:16 / 1:1 |
| 即梦 | Auto（自适应，固定） |

**清晰度**

| 模型 | 可选值 |
|---|---|
| 可灵 | 720P（固定） |
| 即梦 | 480P / 720P / 1080P |

**视频时长**

拖动滑块在 **5s** 和 **10s** 之间选择。

**生成音频**

- 🔊 开启 — 生成视频配音
- 🔇 关闭（默认）

### 引用图片显示

当上游图片节点连入视频节点时，提示词面板中会显示引用图片的缩略图，方便确认参考内容。

### 生成流程

1. 填写提示词
2. 选择模型和参数
3. 点击右下角发送按钮
4. 面板内实时显示进度（每 15 秒轮询一次）
5. 生成完成后视频自动播放

> 图生视频模式下，系统会先将图片上传至云存储，再调用生成接口，这一步会额外耗时约 5~10 秒。

## 脚本节点

脚本节点用于 AI 辅助撰写漫剧脚本，支持流式输出。

输入故事背景和创作要求，AI 实时生成结构化脚本内容（含场景、对白、情节描述）。

---

## 分镜节点

分镜节点以表格形式管理一集或一场景的所有分镜格，每行包含：

- 分镜编号
- 场景描述
- 关联图片
- 备注

可与图片节点联动，将生成的图片直接关联到对应分镜行。

---

## 创作示例

### 图生视频（单帧）

1. 添加一个**图片节点**，上传或生成角色/场景图
2. 添加一个**视频节点**
3. 将图片节点连线到视频节点
4. 选择视频节点，切换到「图生视频」标签
5. 输入运镜描述，如：`相机缓缓拉远，主体居中，光线变化柔和`
6. 选择模型和参数，点击发送

### 首尾帧视频

1. 添加**视频节点**
2. 点击快捷操作「首尾帧生成视频」，自动创建首帧和尾帧图片节点
3. 分别为两个图片节点上传首帧和尾帧图片
4. 切换到「首尾帧」标签，输入过渡描述
5. 发送生成

### 脚本 → 分镜 → 视频流水线

1. 添加**脚本节点**，生成剧情脚本
2. 连接**分镜节点**，整理分镜列表
3. 为每个分镜添加**图片节点**，生成对应画面
4. 为关键场景添加**视频节点**，生成动态镜头

## 提示词技巧

### 视频运镜描述

| 效果 | 提示词示例 |
|---|---|
| 推镜 | `相机缓缓向主体推进，聚焦在面部` |
| 拉镜 | `相机拉远，从特写到全景` |
| 环绕 | `相机环绕主体 360°旋转` |
| 固定 | `固定机位，主体在画面中央` |
| 跟随 | `跟随主体移动，保持主体在画面左三分之一` |

### 图片风格关键词

| 风格 | 关键词 |
|---|---|
| 漫画 | `comic style, cel shading, flat color` |
| 写实 | `photorealistic, 8K, detailed` |
| 概念艺术 | `concept art, matte painting` |
| 赛博朋克 | `cyberpunk, neon, dark city` |
| 古风 | `ancient Chinese style, ink wash, elegant` |

### 通用建议

- **描述要具体**：不说「一个人」，说「一个穿红色夹克的年轻男性，侧脸，低头看手机」
- **先主体后背景**：先描述主角，再描述环境和光线
- **使用负向提示词**：添加不想要的元素，如 `no watermark, no blurry, no distortion`
- **参考帧优先**：有参考图的情况下，AI 理解主体的准确度远高于纯文字描述
