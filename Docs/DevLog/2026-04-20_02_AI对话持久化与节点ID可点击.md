# 2026-04-20_02 AI对话持久化与节点ID可点击

## 概述

本次工作包含三项功能改进：AI 对话历史持久化（刷新不丢失）、节点 ID 在 AI 消息中可点击定位、以及清空对话按钮。

---

## 一、AI 对话持久化（localStorage）

### 问题

AI 助手的对话历史存储在 React state 中，刷新页面后全部丢失。

### 方案

用 `localStorage` 持久化，以项目 ID 为 key，最多保存最近 50 条消息。

#### 关键代码（RightPanel.tsx）

```typescript
const STORAGE_KEY = `ai_chat_messages_${currentProject?.id ?? 'default'}`

// 从 localStorage 懒初始化
const [messages, setMessages] = useState<ChatMessage[]>(() => {
  try {
    const saved = localStorage.getItem(STORAGE_KEY)
    if (saved) {
      const parsed = JSON.parse(saved) as ChatMessage[]
      return parsed.map(m => ({ ...m, timestamp: new Date(m.timestamp) }))
    }
  } catch {}
  return [WELCOME_MSG]
})

// 每次 messages 变化时自动持久化
useEffect(() => {
  try {
    const toSave = messages.slice(-50).map(m => ({
      ...m,
      pendingAction: undefined,  // 不保存待确认动作（刷新后无法执行）
      actionStatus: m.actionStatus === 'pending' ? 'cancelled' : m.actionStatus,
    }))
    localStorage.setItem(STORAGE_KEY, JSON.stringify(toSave))
  } catch {}
}, [messages, STORAGE_KEY])
```

### 处理细节

- `timestamp` 字段在 JSON 序列化后变为字符串，读取时用 `new Date()` 反序列化
- `pendingAction` 不保存（刷新后 confirm/cancel 回调失效，跳过更安全）
- 状态为 `pending` 的消息保存时改为 `cancelled`

## 二、节点 ID 在 AI 消息中可点击定位

### 方案

两层保障：

1. **系统提示词指令**：告诉 AI 提及节点 ID 时用反引号包裹（如 `` `libtv_image_123456` ``）
2. **前端正则预处理**：ReactMarkdown 渲染前，自动将消息中裸露的节点 ID 包上反引号

```typescript
// 预处理：把裸 ID 变成 `ID`
const nodeIds = nodesRef.current.map(n => n.id)
const escaped = nodeIds.map(id => id.replace(/[.*+?^${}()|[\]\\]/g, '\\$&'))
const pattern = new RegExp(`(?<![\`\\w])(${escaped.join('|')})(?![\`\\w])`, 'g')
const processed = msg.content.replace(pattern, '`$1`')

// ReactMarkdown 自定义 code 组件：检测是否是节点 ID
code({ children, ...props }) {
  const text = String(children).trim()
  const isNodeId = nodesRef.current.some(n => n.id === text)
  if (isNodeId) {
    return (
      <code
        style={{ cursor: 'pointer', textDecoration: 'underline dotted', color: '#60a5fa' }}
        title="点击定位到该节点"
        onClick={() => focusCanvasNode(text)}
      >{children}</code>
    )
  }
  return <code {...props}>{children}</code>
}
```

### 效果

- AI 回复中提到的节点 ID 显示为蓝色下划线
- 点击后画布自动平移 + 选中该节点（动画时长 400ms）

## 三、清空对话按钮

在 AI 对话面板顶部工具栏加入「清空」按钮（Trash2 图标），点击后清除 localStorage 并重置为欢迎语。

```typescript
const clearMessages = () => {
  localStorage.removeItem(STORAGE_KEY)
  setMessages([WELCOME_MSG])
}
```
