# 2026-04-20_01 AI助手画布感知与启动修复

## 概述

本次工作分两部分：修复本地开发环境启动问题，以及让 AI 助手能够实时感知画布状态。

---

## 一、开发环境启动修复

### 问题排查过程

| 问题 | 原因 | 修复 |
|------|------|------|
| 登录 500 错误 | 前端代理指向 8001，但后端跑在 8000 | 修改 `.env.local` |
| 密码不正确 | 重置写入了错误的 DB 文件（comicflow.db vs comicflow_dev.db） | 用 `os.environ` 覆盖后重置 comicflow_dev.db |
| CORS 拒绝 | `.env` 中 CORS_ORIGINS 未包含 3010 端口 | 追加 `http://localhost:3010` |

### 关键配置

- 后端数据库：`backend/.env` → `DATABASE_URL=sqlite+aiosqlite:///./comicflow_dev.db`
- 前端代理目标：`frontend/.env.local` → `VITE_API_URL=http://localhost:8000`
- 前端实际端口：`npm run dev` 启动在 **3000**（package.json scripts 中 `--port 3000` 覆盖了 vite.config.ts 中的 3010）

### 启动方式

```bash
# 后端
cd backend && uvicorn app.main:app --reload --port 8000

# 前端
cd frontend && npm run dev
# 访问 http://localhost:3000
```

## 二、AI 助手画布感知

### 背景

Phase 2 完成后，AI 可以输出结构化 actions 操作画布，但它本身不知道当前画布上有什么节点。用户问「你能看到项目中的节点吗」时，AI 回答「无法直接查看」。

### 方案

每次发送 AI 消息时，将当前画布快照作为 `context_data` 一起传给后端。

#### 前端改动（RightPanel.tsx）

```typescript
const canvasContext = {
  nodeCount: nodesRef.current.length,
  selectedCount: selectedRef.current.length,
  nodes: nodesRef.current.map(n => ({
    id: n.id,
    type: n.type,
    label: n.label,
  })),
}
const res = await aiApi.chat({
  message: text,
  context_type: 'general',
  context_data: canvasContext,  // 新增
  history,
})
```

#### 后端改动（ai_assistant.py）

将 `context_data` 格式化为可读的画布描述，拼入用户消息：

```python
if request.context_data:
    ctx = request.context_data
    nodes = ctx.get("nodes", [])
    if nodes:
        node_list = "\n".join(f"  - [{n['type']}] {n['label']}" for n in nodes)
        canvas_desc = f"当前画布共 {node_count} 个节点，选中 {selected_count} 个：\n{node_list}"
    else:
        canvas_desc = "当前画布为空（0个节点）"
    user_message = f"【画布状态】{canvas_desc}\n\n【用户消息】{request.message}"
```

### 效果

- AI 现在能回答「画布上有几个节点」「当前有哪些节点」等感知类问题
- AI 可以基于现有节点做更准确的工作流建议（避免重复添加已有节点）
- 每次对话都携带最新快照，无需用户手动告知

### 架构说明

```
用户发消息
  ↓
前端读取 nodesRef（实时画布状态）
  ↓
context_data = { nodeCount, selectedCount, nodes[] }
  ↓
后端格式化为 【画布状态】... 拼入 user_message
  ↓
AI 读取画布状态 + 用户意图 → 返回 { reply, actions[] }
```
