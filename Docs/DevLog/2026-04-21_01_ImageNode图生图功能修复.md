# 2026-04-21_01 ImageNode 图生图功能修复

## 背景

ImageNode 的「图生图」功能设计目标：用户点击「图生图」→ 选择参考图片 →
系统在左侧自动新建一个上游 ImageNode（载入参考图）→ 连边到当前节点 →
当前节点保持选中并展开 Prompt 面板，供用户填写提示词继续生成。

实际表现：什么也没发生，只剩一个图片节点，新节点始终不出现。

---

## Bug 分析

### Bug 1 — 空节点快捷区「图生图」按钮挂错了 handler

```tsx
// 错误：走的是普通上传分支，file input change 事件里 mode === 'upload'
{ Icon: Upload, label: '图生图', onClick: handleUploadClick },

// 正确：应设 fileInputModeRef.current = 'img2img' 再触发 input
{ Icon: Monitor, label: '图生图', onClick: handleImg2Img },
```

`handleUploadClick` 与 `handleImg2Img` 共用同一个 `<input type="file">`，
通过 `fileInputModeRef` 区分模式。按钮挂错导致 `handleFileChange` 里
`mode === 'upload'` 分支执行，新节点永远不会被创建。

### Bug 2 — 新建上游节点携带 `imageSource: 'uploaded'`，Prompt 面板被隐藏

```typescript
// 错误：isUploadedOnly = true → CollapsibleSection 不渲染，面板消失
addNode({ ..., imageSource: 'uploaded', ... })

// 修复：去掉该字段，节点默认可接受 Prompt
addNode({ ..., imageUrl: ref, ... })
```

### Bug 3 — `requestSelectNode` 指向新建节点而非当前节点

图生图完成后，用户需要在**当前节点**填写 Prompt 生成图片，
而代码却将视口 fitView 到新建的参考图节点：

```typescript
// 错误：跳到参考图节点
requestSelectNode(newId)

// 修复：保持当前节点选中 + 居中
requestSelectNode(data.id)
```

---

## 修复内容

| # | 文件 | 变更 |
|---|------|------|
| 1 | `ImageNode.tsx` | 空节点快捷区「图生图」按钮 `onClick` 由 `handleUploadClick` → `handleImg2Img` |
| 2 | `ImageNode.tsx` | img2img 分支新建节点去掉 `imageSource: 'uploaded'` 与 `initialPanelExpanded: true` |
| 3 | `ImageNode.tsx` | img2img 分支 `requestSelectNode(newId)` → `requestSelectNode(data.id)` |

---

## 修复后完整流程

1. 空 ImageNode → 点「图生图」→ 文件选择框弹出
2. 选图 → 新建上游 ImageNode（携带参考图）出现在当前节点左侧，自动连边
3. 当前节点被 `requestSelectNode` 选中并 fitView 居中
4. Prompt 面板随 `showSelected` 展开，用户直接填写提示词即可生成
