## 一、背景

AI 助手面板（RightPanel）在阶段一完成了 Intent 识别和后端对话代理，本次针对实际测试中暴露的 3 个核心问题进行修复，并补充工作流知识和对话历史支持。

## 二、问题与修复

### 问题 1：AI 幻觉节点类型

**现象**：用户询问"有哪些节点"，AI 回答了 14 种节点（剧本解析节点、角色设计节点、场景设计节点……），但画布中实际只能添加 6 种节点。

**根因**：后端 `ai_assistant.py` 中的 system prompt 是从产品设计文档（`CLAUDE_SYSTEM_PROMPT.txt`）复制的，包含了规划中但尚未实现的节点类型。

**修复**：以 `frontend/src/components/nodes/shared/NodeAddMenu.tsx` 的 `MENU_ITEMS` 为唯一真相来源，确认实际可用节点只有 6 种，重写 `PLATFORM_SYSTEM_PROMPT`：

```python
# backend/app/api/v1/endpoints/ai_assistant.py
# 节点列表由 14 种 → 6 种，加明确声明
"""
| 节点名称 | 类型 ID | 说明 |
|---------|--------|------|
| 文本 | `libtv_script` | 输入剧本/描述文字，工作流起点 |
| 图片 | `libtv_image` | 上传或 AI 生成图像，含提示词面板 |
| 视频 | `libtv_video` | 上传或 AI 生成视频（支持 Kling/即梦模型） |
| 视频合成 (Beta) | `auto_edit` | 将多个视频/图片合成为完整视频 |
| 音频 | `tts` | 文字转语音配音 |
| 脚本 (Beta) | `libtv_script_gen` | AI 生成/编辑分镜脚本 |

重要：目前只有以上 6 种节点可用。不存在"剧本解析节点""角色设计节点""场景设计节点"等其他节点。
"""
```

同步更新前端 `src/api/index.ts` 的 `PLATFORM_CONTEXT`（直连模式备用 prompt）。

---

### 问题 2：LIST_NODES Intent 过度匹配平台知识问题

**现象**：用户问"现在有哪些类型的节点可以用"，被识别为 `LIST_NODES` intent，返回当前画布节点列表，而不是 AI 回答平台知识。

**根因**：Intent 正则 `/现在.*节点/` 匹配范围过宽，无法区分"查画布状态"和"查平台知识"。

**修复**（`RightPanel.tsx`）：加负向条件

```typescript
// 修复前
if (/有哪些节点|列出节点|现在.*节点/.test(t)) { ... }

// 修复后：含"类型/功能/介绍/可以用"等词时走 AI，不走 Intent
if (/有哪些节点|列出节点|查看节点|节点列表|现在.*节点/.test(t)
    && !/类型|功能|介绍|说明|支持|系统|平台|可以用|可用/.test(t)) { ... }
```

### 问题 3：Markdown 表格渲染为原始文本

**现象**：AI 返回的表格（`| 节点 | 说明 |`）显示为纯文本，没有渲染成 HTML 表格。

**根因**：`react-markdown` v10 默认不解析 GFM（GitHub Flavored Markdown）语法。

**修复**：

```bash
npm install remark-gfm
```

```tsx
// RightPanel.tsx
import remarkGfm from 'remark-gfm'
<ReactMarkdown remarkPlugins={[remarkGfm]}>{msg.content}</ReactMarkdown>
```

在 `globals.css` 补充 `.markdown-body` 暗色主题样式，覆盖表格、代码块、blockquote、标题等 GFM 元素。

## 三、新增功能

### 3.1 对话历史上下文

`AssistantRequest` 新增 `history` 字段，后端将最近 10 轮对话追加到 messages，让 AI 理解上下文：

```python
# AssistantRequest
history: Optional[list[dict]] = None  # [{"role": "user"|"assistant", "content": "..."}]
```

前端 `RightPanel.tsx` 发送请求时自动携带当前聊天记录（最近 20 条消息转换为 history 格式）。

### 3.2 工作流场景知识（修正版）

旧 system prompt 的"常见创作场景"引用了不存在的节点，全部替换为基于真实 6 种节点的场景：

| 场景 | 节点链路 |
|------|---------|
| 图文转视频 | 文本 → 图片 → 视频 → 视频合成 |
| 带配音短片 | 文本 → 音频(TTS) + 图片 → 视频 → 视频合成 |
| AI 脚本创作 | 文本 → 脚本(Beta) → 图片×N → 视频×N → 视频合成 |

同时补充了节点连接方式说明（output handle 拖拽到 input handle、并行分支等）。

## 五、架构备注

- **知识同步问题**：system prompt 目前为硬编码字符串。新增节点类型时需手动同步 `ai_assistant.py`、`api/index.ts` 两处。建议后续将节点定义抽为单一配置文件，由构建脚本自动注入 prompt。
- **画布状态感知（待做）**：AI 目前无法感知当前画布节点状态。可将 `canvas_state` 附在请求的 `context_data` 中（字段已预留），对应设计方案见 `2026-04-18_02`。
