# img2prompt 图片节点修复

**日期：** 2026-04-14  
**涉及文件：**
- `frontend/src/components/nodes/ImageNode.tsx`

---

## 功能说明：图片反推提示词

点击 ScriptNode 快捷操作"图片反推提示词"后：

1. 左侧自动创建一个 ImageNode，带有内置默认占位图（`DEFAULT_IMAGE_URL = 'default://placeholder'`），连线到 ScriptNode
2. ScriptNode 提示词面板显示该图片的缩略图引用，提示词自动填入固定文案
3. 用户上传自己的图片替换默认图后，点发送，AI 进行图片反推

---

## 问题现象

点击"图片反推提示词"后，创建的 ImageNode：
1. **显示空态**（山形图标 + 快捷操作），而非默认图片
2. **图片比例变形**（宽度 400px 但高度按竖图比例拉伸）

---

## 根因分析

### 根因一：渲染分支错误排除 `DEFAULT_IMAGE_URL`

在修复"刷新尺寸跳变"问题时，引入了 `hasImageData` 辅助变量：

```ts
const hasImageData = !!data.imageUrl && data.imageUrl !== DEFAULT_IMAGE_URL && !imgBroken
```

该变量设计目的是"是否有**持久化尺寸**可用"（`DEFAULT_IMAGE_URL` 没有存储的 `renderedW/H`），但被错误地复用到渲染分支判断：

```tsx
// 错误写法：DEFAULT_IMAGE_URL 被排除，节点永远显示空态
{(data.imageUrl && data.imageUrl !== DEFAULT_IMAGE_URL && !imgBroken) ? (
  /* 图片模式 */
) : (
  /* 空态 */
)}
```

### 根因二：nodeW / imageAreaH 通过 `hasImageData` 门控导致比例变形

```ts
// 错误写法
const nodeW      = (hasImageData && imgRenderedW) ? imgRenderedW : NODE_W
const imageAreaH = (hasImageData && imgRenderedH) ? imgRenderedH : PLACEHOLDER_H
```

`DEFAULT_IMAGE_URL` 节点的 `hasImageData = false`，所以：
- `nodeW = NODE_W = 400px`（容器撑到全宽）
- `imageAreaH = PLACEHOLDER_H = 220px`
- `<img style={{ width: '100%' }}>`：图片被强制拉伸至 400px 宽，高度 `auto` → 比例变形

---

## 修复方案

### 1. 渲染分支还原

```tsx
// 正确：DEFAULT_IMAGE_URL 是真实图片，应显示图片模式
{(data.imageUrl && !imgBroken) ? (
```

### 2. nodeW / imageAreaH 直接使用 imgRenderedW/H

```ts
// 正确：imgRenderedW/H 已由 useState(data.renderedW ?? null) 正确初始化
const nodeW      = imgRenderedW ?? NODE_W
const imageAreaH = imgRenderedH ?? PLACEHOLDER_H
```

`imgRenderedW` 来源：
- 页面刷新时：从 `data.renderedW`（IndexedDB 持久化值）初始化
- 首次加载图片时：`handleImgLoad` 计算后赋值，同时写入 IndexedDB
- `DEFAULT_IMAGE_URL` 新节点：`imgRenderedW = null`，容器初始 400px，图片 onLoad 后算出正确尺寸并收窄，有 150ms 过渡动画

### 3. widthReady 初始值放宽

```ts
// 修复前：DEFAULT_IMAGE_URL 被排除，首次渲染没有过渡动画
const [widthReady, setWidthReady] = useState(
  !!(data.imageUrl && data.imageUrl !== DEFAULT_IMAGE_URL && data.renderedW)
)

// 修复后：只要有持久化尺寸就启用过渡
const [widthReady, setWidthReady] = useState(
  !!(data.imageUrl && data.renderedW)
)
```

## 最终行为

| 场景 | 行为 |
|------|------|
| 点击"图片反推提示词" | 创建带默认占位图的 ImageNode，显示图片模式 |
| ScriptNode 提示词面板 | 显示上游图片缩略图引用 |
| 节点初始渲染 | 容器 400px → 图片加载后收窄至正确比例（150ms 过渡） |
| 用户替换图片 | 按新图片比例重新计算尺寸 |
| 页面刷新 | 从 IndexedDB 读取 renderedW/H，直接渲染正确尺寸，无跳变 |
