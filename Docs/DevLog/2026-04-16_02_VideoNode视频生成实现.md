# 2026-04-17 VideoNode 视频生成实现（可灵 + 即梦，通过 LightAI 统一接口）

## 功能背景

在 VideoNode 上接入真实的 AI 视频生成能力，支持两个模型：

- **可灵（Kling v3）**：快手出品，`service_name="keling"`
- **即梦（Doubao Seedance 1.5 Pro）**：字节跳动，`service_name="volces_ark"`

两者均通过 **LightAI 统一异步任务接口**调用，与图片生成方式完全一致，复用同一个 LightAI API Key，无需单独配置可灵/即梦密钥。

---

## 技术方案

### 统一接口流程

```
1. POST /api/lightai/create_async_task  → 获得 task_id
2. GET  /api/lightai/get_task_status/{task_id}  轮询（每 15s）
3. status === 2 时从响应中提取视频 URL
```

### 请求体结构

**可灵文生视频：**
```json
{
  "service_name": "keling",
  "api_name": "text_to_video",
  "app_info": { "model": "kling-v3", "mode": "pro" },
  "task_query": {
    "json": { "prompt": "...", "model_name": "kling-v3", "duration": 5, "aspect_ratio": "16:9", "mode": "pro", "sound": "off" }
  }
}
```

**可灵图生视频：**
- `api_name` 改为 `"image_to_video"`
- `task_query.json` 加入 `image`（COS URL）和可选的 `image_tail`（尾帧）

**即梦视频：**
```json
{
  "service_name": "volces_ark",
  "api_name": "video30_generate",
  "app_info": { "model": "doubao-seedance-1-5-pro-251215", "mode": "" },
  "task_query": {
    "json": {
      "model": "doubao-seedance-1-5-pro-251215",
      "ratio": "adaptive", "duration": 5, "resolution": "720p",
      "generate_audio": false, "watermark": false,
      "content": [{ "type": "text", "text": "..." }]
    }
  }
}
```

### 图生视频：先上传 COS

可灵和即梦的图生视频 API 只接受 COS URL，不接受 base64。因此上游节点传入的图片需先上传：

```
POST /api/lightai/upload_cos  (multipart/form-data)
  image_file = <blob>
  cos_path   = skill_api/user_upload/{timestamp}_frame.png
→ 返回 download_url（COS 公开访问链接）
```

上传成功后将 `download_url` 作为 `image` / `image_tail` 传入视频任务。

## 配置

只需一个 LightAI API Key 即可驱动所有视频生成：
```env
VITE_LIGHTAI_API_KEY=your_lightai_api_key
```

或在设置面板 → LightAI → API Key 中填写。
