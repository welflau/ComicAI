# 2026-04-29_01 ScriptNode 生成角色图节点流程

## 背景

ScriptGenNode 已能「按分镜批量生成镜头图节点」（见 `2026-04-21_07`），但漫画工作流还缺失**角色一致性**入口：同一角色在不同镜头之间形象漂移，只能靠用户手动维护角色参考。

希望从剧本文本直接提取所有登场角色，为每个角色创建一张独立的「角色图」节点（`libtv_image`），供下游分镜引用。与 ScriptGenNode 的镜头生成形成对称入口。

---

## 设计

用户操作流程：

1. 选中 ScriptNode，且 `content` 模式下有正文
2. 卡片上方浮出「生成角色图」按钮（与已有的「img2prompt」等快捷操作同属工具条区域）
3. 点击后进入选择模式，卡片下方展开「角色列表」面板
4. 后台流式调 AI 提取角色，面板显示「识别中…」Loader
5. 识别完成后，列表列出每个角色的 **名字 + 完整外貌/人设描述**（2 行截断），默认全选
6. 支持全选 / 半选（indeterminate）/ 逐行勾选
7. 底部「⚡生成 N 张」紫色主按钮：每个选中角色创建一个 `libtv_image` 节点并连线，退出选择模式
8. 随时 ✕ 或取消选中节点退出选择模式，中断进行中的提取

## 实现

### 新增 state

```ts
interface CharItem { id: string; name: string; description: string }

const [charGenMode, setCharGenMode]           = useState(false)
const [characters, setCharacters]             = useState<CharItem[]>([])
const [selectedCharIds, setSelectedCharIds]   = useState<Set<string>>(new Set())
const [charExtractStatus, setCharExtractStatus] = useState<'idle' | 'extracting' | 'done' | 'error'>('idle')
const charAbortRef = useRef<AbortController | null>(null)
```

### AI 提取 — 专用 system prompt

复用现有 `streamAI`，通过 `systemOverride` 覆盖系统提示词，要求 AI **仅**返回 JSON 数组：

```ts
streamAI({
  prompt: text,
  systemOverride: `你是角色提取助手。从用户提供的文本中，识别所有独立的角色或人物，
提取每个角色的完整外貌/人设描述。严格输出 JSON 数组，格式如下，不要输出任何其他内容：
[
  { "name": "角色名", "description": "完整外貌与人设描述，尽量详细，适合作为AI绘图提示词" },
  ...
]
如果文本中找不到任何角色，返回空数组 []。`,
  contextType: 'general',
  onChunk: c => { raw += c },
  onDone: () => { /* 提取第一个 [...] 块解析 */ },
  onError: () => setCharExtractStatus('error'),
  signal: ctrl.signal,
})
```

**容错解析**：从累计 raw 中取第一个 `[` 到最后一个 `]` 再 `JSON.parse`，兼容 AI 输出前后可能夹带的多余文本；失败写日志 `角色提取解析失败` 并标红。

### 「生成角色图」按钮

只在满足以下条件时显示（避免误触）：
- `!editing`（非编辑态）
- `showSelected`（节点被选中 / 悬停）
- `!charGenMode`（未在选择模式中）
- `text.trim().length > 0`（文本非空）

位置在卡片上方 `ZoomInvariantPanel` 里，与节点本体一起缩放时保持固定像素，`marginBottom: 8`。

### 角色列表面板

- 头部：紫色 `Users` 图标 + "角色列表"，右上 ✕ 退出
- 识别中：`Loader2` 自转 + "识别中…"
- 识别失败：红色 "提取失败"
- 全选行：14px 紫色 checkbox，全选 / 半选（中间一条短横）/ 无选三态
- 每行角色：checkbox + 名字 + 描述（`-webkit-line-clamp: 2` 截两行），hover 深灰，选中加紫色背景
- 最大高度 220px，溢出竖向滚动

### 底部操作栏（识别完成时）

```ts
onClick={() => {
  const selected = characters.filter(c => selectedCharIds.has(c.id))
  const SPACING_Y = 260
  const startX = data.position.x + NODE_W + 80
  const startY = data.position.y - ((selected.length - 1) * SPACING_Y) / 2
  selected.forEach((char, idx) => {
    const newId = `libtv_image_${Date.now()}_${idx}`
    addNode({
      id: newId, type: 'libtv_image',
      label: char.name,
      category: 'output',
      position: { x: startX, y: startY + idx * SPACING_Y },
      config: {},
      title: char.name,
      imagePrompt: char.description,
    } as NodeData)
    addEdge({ id: `e-${data.id}-${newId}`, source: data.id, target: newId })
  })
  setCharGenMode(false)
  addLog({ level: 'info', category: 'operation',
    message: `生成 ${selected.length} 个角色图节点`,
    detail: selected.map(c => c.name).join('、') })
}}
```

节点布局与 ScriptGenNode 的镜头生成一致：在右侧 `NODE_W + 80` 处列一列，以 ScriptNode Y 坐标为中心，260px 垂直间距上下平铺。

### 自动退出

节点取消选中时，`useEffect` 监听 `selected` 变化：清理 `charGenMode / characters / selectedCharIds / charExtractStatus` 并 `abort()` 进行中的请求，避免残留状态。

## 与 ScriptGenNode 的设计对称性

| 节点 | 输入 | 提取 | 批量创建 | 下游语义 |
|---|---|---|---|---|
| `ScriptNode` | 剧本正文 | AI 识别**角色** | `libtv_image × N` | 角色图（consistency 参考） |
| `ScriptGenNode` | 分镜表 | 用户勾选**镜头** | `libtv_image × N` | 镜头图（storyboard） |

两者共同构成漫画工作流的「角色一致性 + 分镜生成」双入口，用户可组合使用：
1. ScriptNode 先生成 N 张角色图 →
2. 接 ScriptGenNode 生成分镜 →
3. ScriptGenNode 勾选镜头生成镜头图，镜头图通过参考连线引用角色图
