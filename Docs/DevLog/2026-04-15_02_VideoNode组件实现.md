### 2. 遵守节点共同约定

- **handles 可见性：** `isHovered || (!!selected && !dragging)`，opacity 150ms 过渡
- **边框颜色：** 默认 `#2a2a2a` → hover `#3a3a3a` → selected `#707070`，150ms 过渡
- **选中发光：** `box-shadow: 0 0 0 2px rgba(255,255,255,0.04), 0 4px 20px rgba(0,0,0,0.5)`
- **多选抑制：** 使用 `useIsMultiSelected()` hook，多节点选中时不显示单节点 selected 样式
- **浮动上传按钮：** `top: -38px, left: 50%, transform: translateX(-50%)`，只在 `selected && !dragging && !hasVideo` 时显示
- **CollapsibleSection：** 选中时展开提示词面板，失焦自动收起
- **initialPanelExpanded：** 从 `+` 菜单创建时面板默认展开，失焦后恢复正常选中行为
- **ZoomInvariantPanel：** 提示词面板包裹在缩放不变容器内，画布缩放时面板保持固定屏幕尺寸
- **`className="nodrag nopan"`：** 所有交互元素防止意外触发节点拖拽
- **`nowheel`：** textarea 上防止滚轮滚动穿透到画布

## 完整数据链路（新建视频节点）

```
用户在任意节点点 + → 选"视频"
  → NodeAddMenu: addNode({ type: 'libtv_video', initialPanelExpanded: true, ... })
  → VideoNode 挂载: hadInitialExpand = true
  → CollapsibleSection expanded = true（面板立即展开）

用户点击画布其他区域（节点失去选中）
  → selected = false
  → useEffect: setHadInitialExpand(false)
  → CollapsibleSection expanded = false（面板收起）

用户再次单击节点
  → selected = true
  → CollapsibleSection expanded = true（正常选中展开）
```
