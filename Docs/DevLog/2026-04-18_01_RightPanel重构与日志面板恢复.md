# 2026-04-18 RightPanel 重构、日志面板恢复与 AI 助手面板优化

## 背景

上一阶段实现了 ImageNode 图片工具栏（8个端点），但引入了两个问题：
1. 新增的 `RightPanel`（属性/AI助手/运行日志三 tab）没有被渲染到 `ProjectEditor`，导致 AI 面板从未出现
2. `ImageEditToolbar` 直接引用了 `ImageNode` 内部的 `useCallback` handler，导致运行时 `ReferenceError: handleOptimize is not defined`

本次全面修复上述问题并完善日志入口。

---

## 一、ImageNode handler 作用域崩溃修复

### 问题
`ImageEditToolbar` 组件定义在 `ImageNode` 函数**外部**，但代码中直接引用了只存在于 `ImageNode` 内部的 `useCallback` hook：
```
handleMultiAngles, handleLighting, handleCropGrid9,
handleUpscaleHD, handleSplitGrid, handleOptimize,
handleRegenerate, handleFullscreenPreview
```
浏览器控制台报错：`Uncaught ReferenceError: handleOptimize is not defined`

### 修复方案
为 `ImageEditToolbar` 新增 `ImageEditToolbarProps` interface，将所有 handler 改为可选 props 传入：

```tsx
interface ImageEditToolbarProps {
  visible: boolean
  imageUrl?: string
  onMultiAngles?: () => void
  onLighting?: () => void
  onCropGrid9?: () => void
  onUpscaleHD?: () => void
  onSplitGrid?: () => void
  onOptimize?: () => void
  onRegenerate?: () => void
  onFullscreenPreview?: () => void
}
```

`ImageNode` 渲染时将 `useCallback` 函数逐一传入：
```tsx
<ImageEditToolbar
  visible={!!selected && !dragging}
  imageUrl={data.imageUrl}
  onMultiAngles={handleMultiAngles}
  onOptimize={handleOptimize}
  // ...
/>
```

## 四、日志面板恢复独立入口

### 问题
旧版有浮动"日志"按钮可直接打开 `LogPanel`。重构后该入口丢失，详细日志（分类/级别过滤）无法访问。

### 修复：底部状态栏增加"日志"切换按钮

在 `BottomBar` 组件增加常驻日志按钮：
- **平时**：灰色，有 Error/Warn 时变红 + 数字角标
- **激活时**：绿色高亮（`#1e2a1e` 背景 + `#4ade80` 文字），表示日志面板已打开
- **点击**：`logOpen` 状态取反（toggle），再点关闭

```tsx
function BottomBar({ onToggleLog, logOpen, errorCount }: {
  onToggleLog?: () => void
  logOpen?: boolean
  errorCount?: number
})
```

`ProjectEditor` 传入：
```tsx
<BottomBar
  onToggleLog={() => setLogOpen(v => !v)}
  logOpen={logOpen}
  errorCount={errorCount}
/>
```

## 五、AI 助手面板可拖拽宽度

用户需要能手动调整 AI 助手面板宽度。

### 实现
在右侧面板容器左边缘添加 4px 宽拖拽手柄：

```tsx
const [rightPanelWidth, setRightPanelWidth] = useState(260)
const isDraggingPanel = useRef(false)
```

- 悬停时蓝紫色高亮 `rgba(99,102,241,0.4)`
- 拖拽时全局 `cursor: col-resize`，`userSelect: none`
- 宽度限制：`200px ~ 520px`
- 通过 `window.addEventListener('mousemove/mouseup')` 实现跨元素拖拽
