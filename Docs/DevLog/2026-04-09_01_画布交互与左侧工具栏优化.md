## 二、修复内容

### 1. 节点选中状态持久化

**问题：** 左键单击节点后蓝色高亮"一闪而过"，无法持久保持选中状态。

**根因分析：**
ReactFlow 在内部将 `selected` 字段写入节点对象。但 Zustand store 每次更新（如位置变更）都会触发组件 re-render，进而触发 `useEffect(() => { setNodes(rfNodes) })`，将 `rfNodes`（没有 `selected` 字段）覆盖进去，导致选中状态被清除。

**修复（WorkflowCanvas.tsx）：**

使用 `useRef` 追踪上一次 store 快照引用，只在引用真正变化时才同步，并在同步时通过 `selMap` 恢复选中状态：

```tsx
const prevStoreNodes = useRef(storeNodes)

useEffect(() => {
  if (storeNodes !== prevStoreNodes.current) {
    prevStoreNodes.current = storeNodes
    setNodes(nds => {
      const selMap = new Map(nds.map(n => [n.id, n.selected]))
      return rfNodes.map(n => ({ ...n, selected: selMap.get(n.id) ?? false }))
    })
  }
}, [storeNodes, rfNodes])
```

同理对 `storeEdges` 也加了引用比较门控。

### 2. Del 键删除节点

**新增（WorkflowCanvas.tsx）：**

```tsx
deleteKeyCode="Delete"
```

配合 `onNodesDelete` / `onEdgesDelete` 回调，删除后同步写入 Zustand store：

```tsx
const onNodesDelete = useCallback((deleted: Node[]) => {
  const ids = new Set(deleted.map(n => n.id))
  saveWorkflow(
    nodes.filter(n => !ids.has(n.id)),
    edges.filter(e => !ids.has(e.source) && !ids.has(e.target))
  )
}, [nodes, edges, saveWorkflow])
```

### 3. 画布右键上下文菜单

**新增文件：** `CanvasContextMenu.tsx`

菜单项：
| 项目 | 状态 |
|------|------|
| 上传 | 可点击 |
| 保存到我的素材 | 禁用 |
| 添加节点 | 可点击，在鼠标位置插入节点 |
| 撤销 ⌘Z | 禁用 |
| 重做 ⇧⌘Z | 禁用 |
| 粘贴 ⌘V | 可点击 |

通过 `onPaneContextMenu` 钩子触发，使用 `useReactFlow().project()` 将屏幕坐标转换为画布坐标后插入节点：

```tsx
const onPaneContextMenu = useCallback((e: React.MouseEvent) => {
  e.preventDefault()
  const flowPos = project({ x: e.clientX, y: e.clientY })
  setPaneMenu({ x: e.clientX, y: e.clientY, flowX: flowPos.x, flowY: flowPos.y })
}, [project])
```

### 5. 左侧工具栏浮动化

**问题：** 左侧工具栏作为 flex 子元素占据整列宽度，和参考设计不符。

**修复（ProjectEditor.tsx）：**

将布局从 flex row（sidebar + canvas 并列）改为画布全宽 + sidebar 绝对定位叠加：

```tsx
<div style={{ flex: 1, position: 'relative', overflow: 'hidden' }}>
  {activeView === 'workflow' && <WorkflowCanvas />}
  {/* ... */}

  {activeView === 'workflow' && (
    <div style={{
      position: 'absolute', top: '50%', left: 16,
      transform: 'translateY(-50%)', zIndex: 20,
    }}>
      <LeftSidebar />
    </div>
  )}
</div>
```

Icon rail 样式由"侧栏边框"改为"悬浮卡片"：

```tsx
// Before
{ background: '#111', borderRight: '1px solid #1e1e1e' }

// After
{
  background: '#1a1a1a',
  border: '1px solid #2a2a2a',
  borderRadius: 12,
  boxShadow: '0 4px 20px rgba(0,0,0,0.55)',
  position: 'relative',
  zIndex: 30,   // ← 高于遮罩层，确保 hover 切换面板可用
}
```

### 6. 工具栏面板切换失效

**问题：** 面板打开时，背景遮罩（`zIndex: 15`）覆盖了图标按钮，导致鼠标移入其他图标时 `onMouseEnter` 无法触发，面板无法切换。

**修复：** 将 icon rail 的 `zIndex` 设为 `30`，高于遮罩层，使图标始终可被鼠标事件捕获。

### 8. 添加节点菜单：悬停展示描述

**修改（ProjectEditor.tsx）：**

在 `ADD_NODE_ITEMS` / `ADD_RESOURCE_ITEMS` 中新增 `desc` 字段，`LeftSidebar` 内加入 `hoveredId` state：

- 鼠标移入某行 → `hoveredId = item.id` → 描述文字显示在标签下方

| 脚本 | 创意脚本、生成故事板 |
| 上传 | 可上传图片、视频、音频文件 |

## 三、架构说明

| 组件 | 职责 |
|------|------|
| `WorkflowCanvas` | ReactFlow 画布，节点/边状态同步，选中持久化，Del 删除，右键菜单触发 |
| `CanvasContextMenu` | 画布空白区右键菜单（fixed 定位） |
| `NodeContextMenu` | 节点右键菜单（fixed 定位，含复制/副本/删除） |
| `ImageNode` | 图片生成节点，含生成按钮与快捷操作 |
| `LeftSidebar` | 悬浮图标卡片，hover 展开添加节点/工具箱/素材库面板，含悬停描述 |
