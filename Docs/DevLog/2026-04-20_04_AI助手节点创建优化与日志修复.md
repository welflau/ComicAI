# 2026-04-20_04 AI助手节点创建优化与日志修复

## 背景

本次迭代针对 AI 助手创建节点的体验问题进行集中优化，同时修复日志面板的两个噪音问题。

---

## 变更内容

### 1. 日志面板：AI Prompt 条目不再跨会话持久化

**问题**：`logStore` 使用 Zustand `persist` 中间件将所有日志写入 `localStorage`，导致历史 AI Prompt/Response 条目在每次刷新后重新出现，即使用户没有执行任何操作。

**修复**：在 `partialize` 过滤器中排除 `category === 'ai'` 且 `kind === 'prompt' | 'response'` 的条目，这类条目仅在当前会话有意义。

```typescript
// logStore.ts
partialize: (state) => ({
  entries: state.entries
    .filter(e => !(e.category === 'ai' && (e.kind === 'prompt' || e.kind === 'response')))
    .slice(-500),
}),
```

---

### 2. 日志面板：移除 ScriptNode 高频 debug 日志

**问题**：`ScriptNode.tsx` 中有一个 `useEffect` 依赖 `allNodes`，每次移动任意节点时都会触发（节点位置变化导致 `allNodes` 引用更新），画布上有几个 ScriptNode 就打几条 `[ScriptNode] 上游图片检测` debug 日志。

**修复**：直接删除该 debug `addLog` 调用，该日志为开发期排查工具，已完成历史使命。

---

### 3. AI 助手创建节点：在视口中心附近生成

**问题**：AI 助手创建节点时位置固定为 `(100 + index*220, 100)` 的网格，与当前视口位置无关，用户需要手动寻找新节点。

**修复**：改用 `getViewportCenter()` 计算节点初始位置，并加小幅随机偏移避免重叠。同时 `ADD_WORKFLOW` 工作流组合也改为以视口中心为基准水平展开。

```typescript
const center = getViewportCenter()
position: {
  x: center.x - 110 + (Math.random() - 0.5) * 40,
  y: center.y - 80 + (Math.random() - 0.5) * 40,
}
```

---

### 4. AI 助手创建节点：创建后自动定位视口

**问题**：节点创建后视口不移动，用户仍需手动找到新节点。

**修复**：`ADD_NODE` 创建后调用 `focusCanvasNode(newNodeId)`，`ADD_WORKFLOW` 创建并连边后调用 `focusCanvasNode(createdIds[0])`，延迟 100ms 确保节点已渲染。

---

### 5. AI 助手创建节点：自动连接选中节点

**问题**：AI 助手创建的节点是孤立的，用户需要手动拉连线。

**修复**：若创建时画布上**恰好选中一个节点**，自动在选中节点与新节点之间创建一条边。无选中或多选时不连线，避免产生不需要的连接。

```typescript
if (currentSelected.length === 1) {
  setTimeout(() => {
    addEdge({ id: `e_${currentSelected[0]}_${newNodeId}`, source: currentSelected[0], target: newNodeId })
  }, 50)
}
```

---

### 6. AI 助手创建节点：从对话中提取提示词

**问题**：AI 助手创建图片/视频节点时只生成空节点，用户需要再手动输入提示词。

**修复**：在 `matchIntent()` 中新增 `extractPrompt()` 辅助函数，从用户消息里剥离动作词和节点类型关键词后，提取剩余内容作为提示词。例如：
- `"创建一个图片节点，生成猪八戒"` → 提取 `"生成猪八戒"`
- `"帮我加个图片，猪八戒手持九齿钉耙"` → 提取 `"猪八戒手持九齿钉耙"`

提取到的提示词写入 `NodeData.imagePrompt`，确认消息也同步展示提示词内容。

**相关类型变更**：
- `IntentResult` 新增 `nodePrompt?: string`
- `PendingAction` 新增 `nodePrompt?: string`

---

### 7. ImageNode：选中且有提示词时隐藏快捷项目

**约定**：选中状态 + 有提示词内容 → 隐藏「尝试：图生图 / 图片高清」快捷项目，避免与提示词面板争夺视觉焦点。

```tsx
{!hasImage && !hasAnyEdge && !(selected && prompt.trim()) && (
  <div>/* 快捷项目 */</div>
)}
```

同时，当 `initialPanelExpanded` 为 true（AI 预填提示词时）时，占位区高度相应增加以保持节点整体比例。
