# 节点快捷项显示规则统一

**日期：** 2026-04-15  
**涉及文件：**
- `frontend/src/components/nodes/ScriptNode.tsx`
- `frontend/src/components/nodes/ImageNode.tsx`
- `frontend/src/components/nodes/VideoNode.tsx`
- `frontend/src/pages/ProjectEditor.tsx`

---

## 问题背景

各节点快捷操作列表（"尝试："区域）的显示/隐藏逻辑不统一，存在以下问题：

1. **ImageNode / VideoNode**：连接边后快捷项仍然显示，因为只检查了 `e.target === data.id`（仅入边），漏掉了出边作为 source 的情况
2. **ScriptNode**：使用永久存储字段 `data.hideQuickActions` 控制显示，导致从 `+` 菜单创建的文本节点永远不显示快捷项
3. **ScriptNode** 修复后崩溃：`hasIncomingEdge` 使用了尚未声明的 `allEdges`（声明顺序错误）

---

## 统一约定

| 节点类型 | 快捷项显示条件 |
|----------|---------------|
| **文本节点**（ScriptNode） | 无入边（incoming edges） |
| **图片节点**（ImageNode） | 无任何连接边（incoming 或 outgoing） + 无图片内容 |
| **视频节点**（VideoNode） | 无任何连接边（incoming 或 outgoing） + 无视频内容 |

**文本节点特殊规则：** 文本节点是工作流链条的起点，有出边是正常状态，不影响快捷项显示；只有被其他节点连入时才认为"已进入工作流"，此时隐藏快捷项。

---

## 修改详情

### ScriptNode.tsx

**问题一：** 原来使用 `const [showQuickActions, setShowQuickActions] = useState(!data.hideQuickActions)` 控制显示，`data.hideQuickActions` 是创建节点时写死的永久字段，不响应运行时连线变化。

**问题二：** 原来条件包含 `!prompt.trim() && !sourceImageRef`，导致填写了提示词后删除连线，快捷项不恢复。

**修改：**
```typescript
// 删除 showQuickActions state
// 新增（在 allEdges 声明之后）：
const hasIncomingEdge = allEdges.some(e => e.target === data.id)
```

JSX 条件从：
```tsx
{showQuickActions && !prompt.trim() && !sourceImageRef && (
```
改为：
```tsx
{!hasIncomingEdge && (
```

卡片高度计算同步更新：
```tsx
height: !hasIncomingEdge ? 150 : IDLE_CARD_H,
```

### ImageNode.tsx

新增：
```typescript
const hasAnyEdge = allEdges.some(e => e.target === data.id || e.source === data.id)
```

快捷项条件从 `!data.initialPanelExpanded` 改为：
```tsx
{!hasImage && !hasAnyEdge && (
```

### VideoNode.tsx

新增：
```typescript
import { useProjectStore } from '@/stores/projectStore'
const allEdges = useProjectStore(s => s.edges)
const hasAnyEdge = allEdges.some(e => e.target === data.id || e.source === data.id)
```

快捷项条件从 `!hadInitialExpand && !generating` 改为：
```tsx
{!hasVideo && !hasAnyEdge && !generating && (
```

注：`hadInitialExpand` 保留，仍用于 `CollapsibleSection` 的展开逻辑，不再参与快捷项控制。

### ProjectEditor.tsx（LeftSidebar）

修复左侧边栏"视频"节点 ID 错误（`'video'` → `'libtv_video'`），使左侧工具栏能正确创建视频节点：

```typescript
// 修复前
{ id: 'video', ... }
if (!['libtv_script', ..., 'libtv_image'].includes(typeId)) return

// 修复后
{ id: 'libtv_video', ... }
if (!['libtv_script', ..., 'libtv_image', 'libtv_video'].includes(typeId)) return
```

同时将硬编码的三元嵌套改为 `LABELS` / `CATEGORIES` 查找表，并在创建 `libtv_video` 节点时自动传入 `initialPanelExpanded: true`。
