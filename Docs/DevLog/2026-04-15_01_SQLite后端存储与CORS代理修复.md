## 本次修改汇总

### 1. 后端切换到 SQLite（aiosqlite）

**背景：** 开发环境不依赖 PostgreSQL，改用 SQLite 降低本地启动门槛。

**修改：**

`backend/app/core/database.py` — 数据库 URL 改为 aiosqlite：

```python
DATABASE_URL = "sqlite+aiosqlite:///./comicflow.db"
engine = create_async_engine(DATABASE_URL, echo=False)
```

`backend/requirements.txt` — 新增依赖，并锁定版本避免冲突：

```
aiosqlite==0.20.0
fastapi==0.111.0
pydantic==2.7.1
pydantic-settings==2.2.1
pydantic-core==2.18.2
python-jose[cryptography]
passlib[bcrypt]
python-multipart
```

> **踩坑：** pydantic-core 2.41.5 与 fastapi==0.111.0 不兼容，需锁定 pydantic==2.7.1 + pydantic-core==2.18.2。

---

### 2. 后端改跑 8001 端口（8000 被其他服务占用）

```bash
uvicorn app.main:app --reload --port 8001
```

同步更新 `vite.config.ts` 所有代理目标默认值：

```ts
'/uploads': { target: env.VITE_API_URL || 'http://localhost:8001', changeOrigin: true },
'/api':     { target: env.VITE_API_URL || 'http://localhost:8001', changeOrigin: true },
'/ws':      { target: env.VITE_WS_URL  || 'ws://localhost:8001',  ws: true, changeOrigin: true },
```

---

### 3. 修复 CORS 错误（根本原因：VITE_API_URL 非空）

**现象：** 创建/加载项目时 DevTools 报 CORS 错误。

**原因：** `frontend/.env.local` 中 `VITE_API_URL=http://localhost:8001`，导致 axios baseURL 为绝对地址，绕过 Vite proxy，直接发出跨域请求。

**修复：** 清空该变量，让所有请求走 Vite 代理（相对路径）：

```env
# frontend/.env.local
VITE_API_URL=
VITE_WS_URL=
```

---

### 4. 静态文件服务 `/uploads`

`backend/app/main.py` — 挂载本地上传目录：

```python
from fastapi.staticfiles import StaticFiles
app.mount("/uploads", StaticFiles(directory="uploads"), name="uploads")
```

`backend/app/services/storage.py` — 返回相对路径而非绝对路径，前端通过代理访问：

```python
def get_file_url(filename: str) -> str:
    return f"/uploads/{filename}"
```

### 5. IndexedDB → 后端数据迁移

**背景：** 早期版本项目数据存在浏览器 IndexedDB 中（ID 带 `local_` 前缀），现在需要在用户登录后自动迁移到后端数据库。

**新增文件** `backend/app/api/v1/endpoints/migration.py`：

```python
POST /api/v1/migration/projects
# 接收前端传来的 local_ 项目数组，批量写入数据库，返回 id 映射表
```

**`frontend/src/stores/localProjectsStore.ts`** — 新增 `migrateToBackend()`：
- 读取所有 IndexedDB 项目
- 调用迁移接口批量上传
- 成功后在 localStorage 写入 `comicai_migrated_to_backend=1` 标志位

**`frontend/src/App.tsx`** — 登录后触发迁移：

```tsx
useEffect(() => {
  if (isAuthenticated) {
    useLocalProjectsStore.getState().migrateToBackend().catch(...)
  }
}, [isAuthenticated])
```

---

### 6. 修复点击 local_ 项目报 500

**现象：** Dashboard 显示 IndexedDB 旧项目，点击后 `projectStore.loadProject` 将 `local_xxxx` ID 发给后端，后端找不到返回 500。

**修复** `frontend/src/stores/projectStore.ts` — 在 `loadProject` 最顶部拦截 `local_` 前缀：

```ts
if (projectId.startsWith('local_')) {
  const { useLocalProjectsStore } = await import('@/stores/localProjectsStore')
  const localStore = useLocalProjectsStore.getState()
  await localStore.init()
  // 从 IndexedDB 读取并渲染，不走后端接口
  ...
  return
}
```

---

### 7. Dashboard 迁移后不再显示本地项目

**修复** `frontend/src/pages/Dashboard.tsx` — `allProjects` 合并逻辑改为：

```ts
const migrationDone = !!localStorage.getItem('comicai_migrated_to_backend')
const allProjects = migrationDone
  ? projects                                           // 迁移后只显示后端项目
  : (projects.length > 0 ? projects : localProjects)  // 迁移前兜底显示本地项目
```

同时修复 `handleDelete`：`local_` 前缀项目直接走 IndexedDB 删除，不打后端接口。
