# 2026-05-18_01 节点打组与循环遍历实现

## 背景

小说 28 章节节点批量生成后画布混乱，需要打组收纳。
详细设计见 `Docs/节点打组与循环遍历设计方案.md`。

---

## 实现内容

### 1. 数据层扩展（types + projectStore）

**NodeData 新增字段：**
- `groupId?: string` — 节点属于哪个组，根层节点无此字段

**NodeType 新增：**
- `libtv_group` — 组节点
- `libtv_loop` — 循环遍历节点
- `libtv_group_input` / `libtv_group_output` — 组内边界端口节点

**projectStore 新增状态：**
- `currentGroupId: string | null` — 当前所在组，null 表示根层
- `groupNavStack: Array<{ id: string; label: string }>` — 组导航栈

**projectStore 新增 Action：**
- `enterGroup(groupId)` — 进入组，自动创建输入/输出端口节点（首次进入）
- `exitGroup()` — 退出到上一层
- `groupNodes(nodeIds, label)` — 将指定节点打包为组节点

---

### 2. GroupNode 组节点

`frontend/src/components/nodes/GroupNode.tsx`

- 展示标题、子节点数量摘要（过滤端口节点）
- **预览行**：图片节点显示缩略图，文字节点显示内容片段（40字），最多 5 个 + "+N"
- **类型 tag**：图片×N、文字×N 等
- **双击进入组**（`onDoubleClick → enterGroup`），无「进入组」按钮
- 左右 CircleHandle + NodeAddMenu，hover/选中时才显示（规范）
- 选中时紫色高亮边框 + glow

---

### 3. GroupPortNode 端口节点

`frontend/src/components/nodes/GroupPortNode.tsx`

- **输入节点**（蓝色 `#4a9eff`）：代表外部上游数据进入组
- **输出节点**（橙色 `#ff8c42`）：代表组内结果流出到外部下游
- **缩放不变**：用 `useStore(s => s.transform[2])` 读取当前 zoom，内层 div 应用 `scale(1/zoom)`，始终以 88×36px 固定视觉大小显示
- Handle 放在 counter-scaled 内层 div，与视觉边缘对齐
- 进入组时自动创建，不可删除（onNodesDelete 过滤）

---

### 4. LoopNode 循环遍历节点

`frontend/src/components/nodes/LoopNode.tsx`

- 连接上游 GroupNode，读取组内指定类型节点列表
- 遍历类型下拉：文字/图片/章节节点
- 当前项预览（标题 + 内容前 100 字）+ 进度 N/Total
- ◀ 上一个 | ▶ 推送当前 | 下一个 ▶
- **推送当前**：将当前节点的 `content` 注入所有下游节点（`updateNode`）
- hover/选中时才显示 handle

---

### 5. WorkflowCanvas 组导航

- `storeNodes` 按 `currentGroupId` 过滤显示当前层节点
- `storeEdges` 只显示两端都在当前层的连线
- 面包屑导航（进入组时显示，点击可跳回任意层级）
- `onNodeDoubleClick`：group 节点 → enterGroup，其他节点 → fitView
- 进/退组时 `fitView` 只对内容节点（排除端口节点），padding 0.25

---

### 6. 多选打组接入工具条

- `handleMultiGroup`：选中节点 → 调 `groupNodes(ids, label)` → 生成组节点
- `MultiSelectionToolbar` 的「打组」按钮正确传入 `onGroup`
- 从 AddNodePanel 菜单移除「节点组」项（组通过「打组」创建，不需手动添加）

---

### 7. ChapterSplitNode 自动打组

章节数 > 3 时，`handleGenerate` 预先生成 `groupId`，章节节点创建时直接携带 `groupId`，一步到位避免两步时序问题：
- 先 addNode 组节点，addEdge 连接 ChapterSplitNode → 组节点
- 章节节点 addNode 时直接写入 `groupId`
