# AI 助手画布操作能力设计方案

Date: 2026-04-18  
Status: 设计完成，待实现  
Priority: P1

---

## 一、背景与目标

当前 AI 助手（RightPanel）只能进行纯文字对话，无法操作画布。  
目标是让用户通过自然语言指令控制画布节点，例如：

- "帮我创建一个图片节点"
- "帮我搭建一个角色设计工作流"
- "删除刚才那个节点"
- "把图片节点连接到视频节点"

---

分两个阶段实施，可独立上线。

```
阶段一（P1）：前端本地 Intent 识别   ← 简单快速，今天能做完
```

## 三、阶段一：前端本地 Intent 识别

### 3.1 原理

在 `sendMessage()` 发送前，先做本地正则/关键词匹配。  
命中 intent 后**直接执行操作**，不走后端 AI，同时在对话中显示确认消息。

```
用户输入
  │
  ▼
matchIntent(text)  ←── 本地正则匹配
  │
  ├── 命中 → 执行 action → 回复确认文字（不请求后端）
  │
  └── 未命中 → 正常走 aiApi.chat()
```

### 3.2 支持的 Intent

| Intent | 触发关键词示例 | 执行操作 |
|--------|--------------|----------|
| `ADD_NODE` | 创建/添加/新建 + 图片/视频/文本/脚本 | `addNode()` |
| `DELETE_SELECTED` | 删除/移除 + 选中/这个/当前 | `deleteNode(selectedNodeIds[0])` |
| `CLEAR_CANVAS` | 清空画布/全部删除 | 遍历删除所有节点 |
| `LIST_NODES` | 现在有哪些节点/列出节点 | 返回当前节点列表文字 |

### 3.3 节点类型映射

```ts
const NODE_KEYWORDS: Record<string, string> = {
  '图片': 'libtv_image',
  '图像': 'libtv_image',
  '视频': 'libtv_video',
  '文本': 'libtv_script',
  '文字': 'libtv_script',
  '剧本': 'libtv_script',
  '脚本': 'libtv_script_gen',
}
```

### 3.4 代码实现位置

**文件**：`frontend/src/components/panels/RightPanel.tsx`  
**函数**：`matchIntent(text: string, context: IntentContext): IntentResult | null`

```ts
interface IntentContext {
  nodes: NodeData[]
  selectedNodeIds: string[]
}

interface IntentResult {
  intent: 'ADD_NODE' | 'DELETE_SELECTED' | 'CLEAR_CANVAS' | 'LIST_NODES'
  nodeType?: string       // ADD_NODE 时使用
  nodeLabel?: string
  confirmText: string     // 显示在对话框的确认文字
}
```

### 3.5 UI 交互

命中 intent 后，AI 消息气泡显示确认文字 + 绿色操作标记：

```
┌─────────────────────────────┐
│ 🤖 已为你在画布中添加了      │
│    「图片节点」              │
│    ✦ 操作已执行              │  ← 绿色小标签
└─────────────────────────────┘
```

### 3.6 局限性

- 只能识别固定句式，自然语言理解能力弱
- 不支持复合指令（"创建3个节点并连接"）
- 不理解上下文（"删除刚才那个"中的"那个"）

## 四、阶段二：后端 Function Calling

### 4.1 原理

后端 AI 接口返回结构化 `actions` 数组，前端解析并批量执行。

```
前端发送：
{
  "message": "帮我搭建角色设计工作流",
  "context_type": "canvas_control",
  "canvas_state": {                    ← 新增：当前画布状态
    "nodes": [...],
    "edges": [...]
  },
  "history": [...]
}

后端返回：
{
  "reply": "已为你创建角色设计工作流，包含3个节点并自动连接。",
  "actions": [                         ← 新增字段
    { "type": "add_node", "node_type": "libtv_script", "label": "角色描述", "position": {"x": 100, "y": 200} },
    { "type": "add_node", "node_type": "libtv_image",  "label": "角色参考图", "position": {"x": 350, "y": 200} },
    { "type": "add_node", "node_type": "libtv_video",  "label": "角色动画",   "position": {"x": 600, "y": 200} },
    { "type": "connect",  "from": "node_0", "to": "node_1" },
    { "type": "connect",  "from": "node_1", "to": "node_2" }
  ]
}
```

### 4.2 支持的 Action 类型

| action.type | 参数 | 前端执行 |
|-------------|------|----------|
| `add_node` | `node_type`, `label`, `position?` | `addNode()` |
| `delete_node` | `node_id` | `deleteNode()` |
| `connect` | `from`, `to` | `addEdge()` |
| `set_config` | `node_id`, `config` | `updateNode()` |
| `select_node` | `node_id` | `selectNodes()` |
| `clear_canvas` | — | 遍历删除 |

### 4.3 后端改动

**文件**：`backend/app/api/ai.py`

```python
# 现有结构
@router.post("/chat")
async def chat(req: ChatRequest):

    return {"reply": reply}

# 改造后

async def chat(req: ChatRequest):
    result = await ai_service.chat_with_actions(
        message=req.message,
        history=req.history,
        canvas_state=req.canvas_state,  # 新增

    return {
        "reply": result.reply,
        "actions": result.actions,      # 新增，可为空列表
```

### 4.4 前端改动

**文件**：`frontend/src/api/index.ts`

```ts
  message: string

  history?: { role: string; content: string }[]
  canvas_state?: { nodes: NodeData[]; edges: EdgeData[] }  // 新增

// ChatResponse 新增字段

  reply: string

```

**文件**：`frontend/src/components/panels/RightPanel.tsx`

```ts
// 收到 actions 后执行
const executeActions = (actions: CanvasAction[]) => {
  for (const action of actions) {
    switch (action.type) {
      case 'add_node':
        addNode({ id: `${action.node_type}_${Date.now()}`, type: action.node_type, ... })
        break
      case 'delete_node':
        deleteNode(action.node_id)
        break
      case 'connect':
        addEdge({ id: `e_${Date.now()}`, source: action.from, target: action.to })
        break
    }
  }
}
```

## 六、风险与注意事项

1. **画布状态上传**：每次对话携带完整 canvas_state 可能导致请求体过大，需限制节点数量（建议 ≤ 50 个节点时才传）
2. **Action 执行失败**：部分 action 可能因节点 ID 不存在而失败，需要容错处理
3. **撤销支持**：执行 AI actions 后应支持 Ctrl+Z 撤销，需要确认 projectStore 的 undo 机制是否覆盖 addNode/deleteNode
4. **并发问题**：AI 回复过程中用户手动修改画布，action 执行时节点 ID 可能已变化
