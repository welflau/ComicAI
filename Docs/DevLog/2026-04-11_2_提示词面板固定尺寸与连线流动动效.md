# 提示词面板固定尺寸与连线流动动效

**日期：** 2026-04-11

---

## 背景

本次迭代解决两个视觉体验问题：

1. **提示词面板随画布缩放变形**：ImageNode 和 ScriptNode 的 PromptPanel 会随画布 zoom 同步缩放，导致字号/控件在高倍放大时过大、缩小时无法阅读。用户期望面板始终保持固定的屏幕像素尺寸，且居中对齐。

2. **连线缺乏视觉引导**：节点之间的连接线是静态的深灰线条，无法直观感受数据流向。用户希望添加类似"光流脉冲"的动态效果。

---

## 一、ZoomInvariantPanel —— 抗缩放提示词面板

### 原理

ReactFlow 画布对所有节点统一应用 `scale(zoom)` CSS 变换。要让某个子元素在视觉上保持固定像素大小，需要对其施加反向变换 `scale(1/zoom)`，同时保证父容器在 flow 空间中占用正确的缩减后高度（供 `CollapsibleSection` 的 `scrollHeight` 测量使用）。

```
视觉尺寸 = 原始尺寸 × zoom × (1/zoom) = 原始尺寸  ✓
```

### 居中对齐

内层 div 使用 `position: absolute` + `transformOrigin: 'top left'`。缩放后视觉宽度为 `naturalWidth / zoom`，为使其在节点宽度 `naturalWidth` 内居中：

```
left + (naturalWidth / zoom) / 2 = naturalWidth / 2
→ left = (naturalWidth / 2) × (1 - 1/zoom)
```

- zoom = 1 时：`left = 0`，面板恰好填满节点宽度
- zoom > 1（放大）：`left > 0`，面板右移居中
- zoom < 1（缩小）：`left < 0`，面板左移居中

### 新增文件

**`src/components/nodes/shared/ZoomInvariantPanel.tsx`**

```tsx
export default function ZoomInvariantPanel({ children, naturalWidth }) {
  const zoom = useStore(s => s.transform[2])
  const innerRef = useRef(null)
  const [naturalH, setNaturalH] = useState(0)

  // 每次渲染后测量内容高度，h 变化时才 setState（防无限循环）
  useLayoutEffect(() => {
    if (innerRef.current) {
      const h = innerRef.current.offsetHeight
      if (h > 0 && h !== naturalH) setNaturalH(h)
    }
  })

  const scale = 1 / zoom
  const centreLeft = (naturalWidth / 2) * (1 - scale)

  return (
    <div style={{ position: 'relative', height: naturalH > 0 ? naturalH * scale : undefined, overflow: 'visible' }}>
      <div ref={innerRef} style={{
        position: 'absolute', top: 0, left: centreLeft,
        width: naturalWidth, transformOrigin: 'top left',
        transform: `scale(${scale})`,
      }}>
        {children}
      </div>
    </div>
  )
}
```

## 二、AnimatedFlowEdge —— 连线流动动效

### 效果描述

每条连线上有一个蓝白色发光脉冲点，从 source 端持续流向 target 端，循环播放，直观表现数据流动方向。

### 实现方案

使用 SVG `stroke-dasharray` + `stroke-dashoffset` CSS 动画：

- **底层**：`BaseEdge` 渲染静态深灰贝塞尔曲线（`#555`）
- **上层**：第二条 `<path>` 使用极短 dash（40px 亮段 + 600px 空白），`@keyframes` 让 `stroke-dashoffset` 从 0 匀速减少到 `-(40+600)`，使点沿路径向前移动
- **发光**：SVG `<filter>` 对上层 path 做高斯模糊叠加原图，产生 bloom 效果

```svg
<filter id="glow-{id}">
  <feGaussianBlur stdDeviation="3" result="blur"/>
  <feMerge>
    <feMergeNode in="blur"/>
    <feMergeNode in="SourceGraphic"/>
  </feMerge>
</filter>
```

```css
@keyframes flow-edge {
  from { stroke-dashoffset: 0; }
  to   { stroke-dashoffset: -640; }  /* -(DOT_LEN + GAP_LEN) */
}
```

动画周期 2.4s，纯 CSS 驱动，无 JS requestAnimationFrame 开销。

### 颜色方案

| 状态 | 底线颜色 | 脉冲颜色 |
|------|----------|----------|
| 普通 | `#555` | `#93c5fd`（蓝白） |
| 选中 | `#818cf8` | `#a5b4fc`（靛紫） |
